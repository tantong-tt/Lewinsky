## 文本标注

NexT 主题内置了多种 **提示框** 样式：

{% note primary %}
**主要信息** — 用于强调重要内容。
{% endnote %}

{% note info %}
**提示信息** — 补充说明和背景知识。
{% endnote %}

{% note warning %}
**注意事项** — 容易出错的地方，需要特别留意。
{% endnote %}

{% note danger %}
**危险警告** — 可能导致严重问题的操作。
{% endnote %}

## 代码高亮

C 语言点灯示例，代码块自带 **语言标签** 和 **一键复制** 按钮：

```c
#include <stdio.h>

int main() {
    printf("Hello, Embedded World!\n");
    return 0;
}
```

ARM 汇编示例：

```armasm
    AREA    RESET, CODE, READONLY
    ENTRY
    LDR     R0, =0x40021018     ; RCC_APB2ENR
    LDR     R1, [R0]
    ORR     R1, #0x00000004     ; 使能 GPIOA 时钟
    STR     R1, [R0]
    B       .
    END
```
